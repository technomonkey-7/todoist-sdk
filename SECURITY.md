# Security Policy

## Reporting a vulnerability

Please report security issues to https://github.com/technomonkey-7/todoist-sdk/security/advisories/new.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/technomonkey-7/todoist-sdk/issues

## Scope

This policy applies to the generated Arda Çankaya SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Todoist public API, generated by
Arda Çankaya. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
